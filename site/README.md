# Rivet site

This is a dependency-free static documentation site. `python tools/site/build.py` copies it to `site-build/` for GitHub Pages deployment. The site uses the canonical Rivet SVG logo and generated simulator evidence under `assets/`; `tools/media/generate.py` regenerates the PNG and GIF visuals from real local runs. No stock screenshots, fabricated hardware imagery, or unverified video is included.
