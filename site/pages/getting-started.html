Five minutes to a local run

Getting started

Rivet runs without Pi hardware through its deterministic simulator. Install the project, run diagnostics, then explore capabilities and safety boundaries.

Install

python -m pip install -e ".[dev]"
python -m rivet doctor --verbose
python -m rivet run --simulate

Explore

python -m rivet discover
python -m rivet tree
python -m rivet preflight
python -m rivet run --simulate --fault motion.left-wheel

Next

Use rivet init to create a local JSON configuration, then explore roles, skills, missions, SDK schemas, and the examples in the repository.
