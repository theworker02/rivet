# Code of Conduct

Rivet contributors are expected to communicate respectfully and constructively.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, deliberate disruption, and unsafe instructions presented as verified robotics guidance.

Project maintainers may remove comments, close discussions, or restrict participation when necessary to protect contributors and users. Report conduct concerns privately to the project maintainers through the contact channel configured for the repository; do not include sensitive personal data in public issues.
