# Governance

Rivet is currently maintained as an open beta project by its contributors.

Until a formal maintainer group is established:

- changes require review by a project maintainer;
- safety, security, and release changes require explicit rationale and validation;
- compatibility changes must document migration impact;
- no single contributor may silently weaken emergency-stop, lease, or authority behavior;
- releases are prepared from tagged commits after CI and package checks pass.

This document will be revised when the repository has an established owner and decision-making group.
