# Rivet SDK

The SDK examples are intentionally thin adapters over the stable `RobotRuntime` API. `sdk/python/client.py` exposes discovery, tree rendering, and authority acquisition without inventing a second command bus.

The JSON schema under `schemas/` documents the capability contract consumed by applications and tooling.
